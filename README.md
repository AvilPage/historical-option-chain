# Historical Option Chain

View NSE option chain data for any historical date. Built with React (Vite).

**Live:** [historical-option-chain.avilpage.com](https://historical-option-chain.avilpage.com)

> The data pipeline (Python backend) has moved to a separate repository:
> [AvilPage/historical-option-chain-data](https://github.com/AvilPage/historical-option-chain-data)

## Setup

```bash
npm install
```
